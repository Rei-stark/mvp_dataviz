# MVP DataViz

Aplicacao Streamlit para carregar arquivos CSV, inspecionar os dados e criar visualizacoes interativas.

## Como executar

1. Crie e ative um ambiente virtual.
2. Instale as dependencias:

```powershell
python -m pip install -r requirements.txt
```

3. Inicie a aplicacao:

```powershell
streamlit run mvp_dataviz.py
```

4. Envie um CSV com pelo menos duas colunas numericas.
